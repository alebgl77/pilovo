# Web integrations — Pilovo 0.4.0 Preview

Pilovo observes selected interface indicators on [ChatGPT](https://chatgpt.com/) and [Claude](https://claude.ai/) using your normal web accounts. No API key, CLI or companion is needed. Provider account rules, plans and quotas apply.

## Optional observation per site

Enable each provider separately. A grant permits matching-tab recognition, a dynamic isolated observer and focus. The observer samples bounded status controls; it does not collect conversation bodies, prompt/response text, tab titles, cookies or credentials. See [Privacy](privacy.md).

The panel can show working, response-ready attention after witnessed work and debounce, recognized requests/errors, or unknown evidence. Ready is not task success. Seen is a local acknowledgment. The [compatibility table](compatibility.md) records the initial experimental EN/FR coverage and the Claude quota false-completion example.

Without permission, after revocation, or when evidence expires, activity is unknown. The fixed official home page can still be opened. Activity metadata is ephemeral, and restarts need fresh evidence. Provider page throttling may prevent timely refresh; badge cleanup is best effort.

## Manual preparations

Prepare a title/prompt and optional mission. Retention begins off, so copy before closing unless you explicitly save the prompt. Separately open the provider, paste and send there yourself. Sent/completed preparation labels remain your declarations; observation does not rewrite them.

No prompt is put into a URL or injected into a conversation. Pilovo does not click approvals or offer stop, pause, resume or launch commands.

## Unsupported integrations and historical records

ChatGPT agent, Claude in Chrome and Claude Code/Codex are not qualified live integrations. Tab presence and the existence of another product's browser bridge do not create an accessible supervision contract. Broader integration is a [future target](activity-manager-prd.md).

Earlier native receipts retain their original provenance. Native connectors remain disabled. `companion/`, native tests and historical install/package scripts are archived reference; they are not compiled by the default build or included in the Chrome ZIP. Use `npm run package` for the current Pilovo workflow; its historical script filename is not a runtime dependency.

A different extension identity has separate storage. Export before uninstalling; automatic merge/import is absent. Updating Pilovo does not remove independently installed historical companions, provider data, configurations or exports.
