# Briefoak 0.3.0

Briefoak is **a local prompt desk for Claude & ChatGPT**, now published under the MIT license.

1. Prepare a brief and optionally group it in a mission.
2. Copy it, open your provider, then paste and send it yourself.
3. Manually mark it sent/completed and add a local note.

This release introduces the Briefoak identity, English/French documentation, actual UI screenshots with fictional examples, portable source/Chrome packaging and read-only GitHub CI. Prompt retention is off for each new preparation. Exact-site tab recognition is optional; the extension reads no conversations or responses and has no backend, model API, telemetry or native companion requirement.

Download the **Chrome ZIP**, extract it, then use **Load unpacked** in `chrome://extensions` with Developer mode enabled. Select the folder containing `manifest.json`. Chrome 120+ is required. The Source ZIP includes the build scripts and lockfile; Node.js 22.12+ is required to build it.

**This is an unpacked preview, not a Chrome Web Store listing.** Provider account rules and quotas apply. Records and exports have no application-level encryption.

Validation on 9 October 2026: typecheck/build passed, 234 unit tests and 7 publication tests passed, and the final build passed 15 Chromium extension test groups with no page or console errors. A real optional-permission dialog remains a manual gate; synthetic permission fixtures do not prove that dialog works. Screen-reader/zoom review remains manual. See the repository's release checks for exact-artifact and remote CI evidence.

Assets include the Chrome ZIP, self-contained Source ZIP, SHA-256 checksums and dependency notices. Older native experiments are not part of the Chrome package. MIT covers the project; third-party components retain their own licenses.
