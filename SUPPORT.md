# Support

Use [GitHub Issues](https://github.com/alebgl77/pilovo/issues) for reproducible bugs, installation problems and feature proposals. Include the Pilovo version, Chrome version, operating system, a short sequence of steps, expected behavior and actual behavior. Redact screenshots and use invented prompts.

Before opening an issue, check [Troubleshooting](docs/faq.md#troubleshooting) ([en français](docs/faq.fr.md#dépannage)).

Do not attach your browser profile, private prompts, exports, credentials or private conversation links. For suspected security problems, read [SECURITY](SECURITY.md) first.

Support is community/maintainer best-effort. There is no staffed help desk, support email or response-time guarantee. Pilovo cannot resolve provider login, subscription, model or quota issues; use the relevant provider's support for those.
