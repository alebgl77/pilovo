# Security reporting

This early project offers best-effort maintenance with no response-time guarantee or security certification. The current release is the focus of fixes; older experimental native packages are not maintained as an active product.

Do not post private prompts, exports, browser profiles, credentials or exploitable details in public issues. Private vulnerability reporting is enabled: [report a vulnerability privately](https://github.com/alebgl77/briefoak/security/advisories/new). Share only the minimum reproduction needed, using fictional data wherever possible.

For a non-sensitive defect, include version, platform, expected behavior and a minimal reproduction with fictional data. See the [privacy notice](docs/privacy.md) for local storage and erasure limits, and [core contract](docs/core-contract.md) for the intended permission and trust boundaries.
